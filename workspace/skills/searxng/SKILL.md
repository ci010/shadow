# SearXNG — Docker Installation

SearXNG is a privacy-respecting metasearch engine. This skill installs it as a Docker container.

## Prerequisites

Docker must be installed. If not, install it first using the `docker-install` skill.

### macOS Compatibility Notes

Docker Desktop requires **macOS 14+**. On older macOS versions:

- **macOS 13.5+**: Use `colima` with `vmType: vz` (Apple's native virtualization, no qemu needed)
  ```bash
  brew install colima docker
  mkdir -p ~/.colima/default
  cat > ~/.colima/default/colima.yaml <<EOF
  cpu: 2
  memory: 2
  disk: 60
  vmType: vz
  runtime: docker
  EOF
  colima start
  ```
- **macOS 12 or older**: No easy path. Options:
  - Install qemu via brew (requires ghcr.io access for bottles — may fail in restricted networks)
  - Upgrade macOS (recommended)
  - Use a remote Docker host

### colima Binary Install (if brew fails on old macOS)

If `brew install colima` fails due to macOS version or build errors, install binaries directly:

```bash
# colima binary
curl -fsSL -o /usr/local/bin/colima \
  "https://github.com/abiosoft/colima/releases/download/v0.10.1/colima-Darwin-x86_64"
chmod +x /usr/local/bin/colima

# lima (required by colima)
curl -fsSL -o /tmp/lima.tar.gz \
  "https://github.com/lima-vm/lima/releases/download/v1.0.7/lima-1.0.7-Darwin-x86_64.tar.gz"
mkdir -p /tmp/lima-extract
tar -xzf /tmp/lima.tar.gz -C /tmp/lima-extract
cp /tmp/lima-extract/bin/limactl /tmp/lima-extract/bin/lima /usr/local/bin/
cp -r /tmp/lima-extract/share/lima /usr/local/share/lima

# docker CLI binary
curl -fsSL -o /tmp/docker.tgz \
  "https://download.docker.com/mac/static/stable/x86_64/docker-27.5.1.tgz"
tar -xzf /tmp/docker.tgz -C /tmp
cp /tmp/docker/docker /usr/local/bin/docker
chmod +x /usr/local/bin/docker
```

> **Note:** Even with binaries installed, colima still needs qemu (for macOS ≤12) or vz (macOS 13.5+) as the VM backend. On macOS 12, qemu must be installed via brew — if ghcr.io is blocked, this will fail.

## Quick Install

**macOS / Linux** — `searxng-install.sh`:
```bash
bash searxng-install.sh
# Custom port (default: 8888)
bash searxng-install.sh --port=9090
# Custom data directory (default: ./searxng)
bash searxng-install.sh --dir=/opt/searxng
# Remove an existing container and reinstall
bash searxng-install.sh --reinstall
```

**Windows** — PowerShell (`searxng-install.ps1`):
```powershell
.\searxng-install.ps1
# Custom port and directory
.\searxng-install.ps1 -Port 9090 -Dir C:\searxng
# Remove an existing container and reinstall
.\searxng-install.ps1 -Reinstall
```

**Windows** — Command Prompt (`searxng-install.bat`, wraps the `.ps1`):
```cmd
searxng-install.bat
searxng-install.bat --port=9090
searxng-install.bat --dir=C:\searxng
searxng-install.bat --reinstall
```

After installation, SearXNG is accessible at **http://localhost:8888** (or your chosen port).

## Management

```bash
# List running containers
docker container list

# Stop SearXNG
docker container stop searxng

# Start again
docker container start searxng

# Remove container (data is preserved in volumes)
docker container stop searxng && docker container rm searxng

# Shell into the container for debugging
docker container exec -it --user root searxng /bin/sh -l
```

## Configuration

Config lives in `<dir>/config/settings.yml` (mounted at `/etc/searxng`).

Key settings to adjust:
- `server.secret_key` — set a strong random value (auto-generated by the install script)
- `search.formats` — enable `json` if you need the API: `[html, json]`
- `general.instance_name` — friendly name for the instance

After editing settings, restart the container:
```bash
docker container restart searxng
```

## Using the Search API

Enable JSON format in settings first, then:

```bash
# macOS / Linux
curl "http://localhost:8888/search?q=hello+world&format=json"
```
```powershell
# Windows
Invoke-WebRequest "http://localhost:8888/search?q=hello+world&format=json"
```

## Volumes

| Container path       | Description                   |
|----------------------|-------------------------------|
| `/etc/searxng`       | Configuration (settings.yml)  |
| `/var/cache/searxng` | Persistent data (favicon cache)|

## Environment Variables

| Variable             | Description                                     |
|----------------------|-------------------------------------------------|
| `SEARXNG_SECRET`     | Secret key for the instance                     |
| `SEARXNG_BASE_URL`   | Public base URL (e.g. `http://localhost:8888/`) |
