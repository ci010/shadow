# 月升 · Moonrise

一段可以直接在 Shadow 中播放、选镜头、画批注的 8 秒粗剪。两条视频轨，24 fps，共 192 帧（从 0 开始）。两张 PNG 和一段无声 H.264 视频都是为示例制作的原创素材，**不用下载模型或安装剪辑软件**。

## 打开就能试

如果拿到的是 ZIP，请**完整解压**，保持 `cut.otio` 和 `media/` 同级。在 Shadow 的「文件」里从本地工作区打开 `cut.otio`，点监看器下方的播放。直接预览 ZIP 中的时间线或聊天里单独的 `.otio` 附件不会加载旁边的素材；只提供文本读取的远程工作区也不支持视频流。

| 时间线（不含终点） | 你会看到什么 |
| --- | --- |
| 0–2 秒 · 帧 0–47 | V1「暮色山脊」静帧；V2 是 Gap，下层可见。 |
| 2–7 秒 · 帧 48–167 | V1「月升」开始运动。用的是视频源帧 12 起的 144 帧，而不是从源文件开头播放。 |
| 7–8 秒 · 帧 168–191 | V2「观测手记」片尾卡遮住仍在播放的 V1。 |

第 48 帧的切点两侧各有 6 帧转场余量；可以选中 Transition 讨论节奏。Shadow 预览为直接切换，不渲染溶解。

**第一次批注：** 选 V1「02 · 月升」，暂停在时间线第 **96 帧（4 秒）**。可以把焦点放在轨道标尺，按 Home 再按四次 Page Up 精确到达。点「画面批注」，圈出月亮，点「加入对话草稿」。此时引用的是月升片段，时间线第 96 帧对应**源第 60 帧（2.5 秒）**。可以在草稿里接着说：

> 保持这个切点和片段时长，把所选月升素材的入点推迟 6 帧。保留 cut.otio，另存 cut-v002.otio，让我对比。

**再试叠轨：** 在第 168 帧选下轨的「02 · 月升」。用「片段源画面」看山脊，用「时间线」看片尾卡。两次选择指向同一个 Clip，但画面不同；批注会分别记录选中对象和画面来源。

## 从零开始自己的片子

这个示例自带一个**文件夹级、按需读取**的 `video-editor` Skill。要让 Shadow 发现它，把**解压出的 `otio-first-cut` 文件夹本身**选为当前工作区，而不是只打开上层目录中的 `cut.otio`。没有向其他项目安装任何东西。

若要在另一个空工作区复用，只需将 `.agents/skills/video-editor/` 复制到那个工作区的相同位置，再选择那个工作区；已有同名 Skill 时请先比较，不要覆盖。不需要复制示例影片。

在选择好的工作区中，对 Shadow 说：

> 读取 `v:skills/folder/video-editor`。新建「夜航」工程，先按 24 fps 做三个镜头的分镜占位，不生成素材。建好后带我挑第一个镜头。

也可以在本文件夹的终端运行（需要已安装的 Node）：

```sh
node .agents/skills/video-editor/scaffold.mjs "夜航"
```

这会新建 `夜航/cut-v001.otio`、`夜航/shots.md` 和空的 `夜航/media/`。三个 Gap 是 2 秒、4 秒、2 秒的占位，**新架子没有画面是正常的**。把自己的素材放进 `media/` 后，告诉 AI 将哪个 Gap 换成哪个镜头。脚本不联网、不生成媒体，也不复用已经存在的目录。
